# 🛣️ Pothole Detection System

A web-based pothole detection system developed using **Django**, **YOLOv8**, and **OpenCV**. The application detects potholes from images, videos, and live camera feeds, helping improve road monitoring and maintenance.

---

## 🚀 Features

- 📷 Detect potholes from uploaded images
- 🎥 Detect potholes in uploaded videos
- 📹 Real-time live camera detection
- 📍 Automatic location retrieval
- 📧 Email alerts with detected pothole information
- 🖥️ Interactive web interface using Django
- 🎯 Bounding box visualization with confidence scores

---

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/aditimaurya20/Pothole-Detection-System.git
```

Move into the project

```bash
cd Pothole-Detection-System
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the Django server

```bash
python manage.py runserver
```

Open your browser

```
http://127.0.0.1:8000/
```
